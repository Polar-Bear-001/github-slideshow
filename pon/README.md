# ぽんの英単語 — 1日2本の自動制作

幼児向け英語アニメ「ぽんの英単語」（ぽん・ホップ・マフィン・スカイ・ベンの5人が、テーマの英単語10語を言う60.5秒の動画）を、
**1日2回、1話ずつ（縦 1080×1920 と横長 1920×1080 の2本）自動で作る**仕組みです。第1〜20回を手作業で作ったやり方をそのまま自動化しています。

## しくみ

```
スケジュール（毎日 10:13 と 19:13 JST）
   └─ Claude のクラウドセッションが起動し、pon/RUNBOOK.md の手順で1話つくる
        1. 企画   … 未使用のテーマと10語を選び、絵の指示を英語で書く（pon/episodes/epNN.json）
        2. 生成   … Higgsfield で絵21枚（GPT Image）・導入動画1本（Kling 3.0 Turbo）・声11本（ElevenLabs v4）
        3. 検査   … Higgsfield のサンドボックスで位置合わせ・声の高さ/聞き取り・導入動画の崩れ・目視（解剖チェック）
        4. 組立   … 第20回と同じレイアウト・タイミングで縦と横長を書き出し、数値チェック（1815フレーム・音量など）
        5. 納品   … Higgsfield のプロジェクト「ぽんの英単語（自動）」に2本と記録（pon_state）を保存
```

正本はHiggsfieldのサンドボックス `/home/user/pon-repo/pon/`（このフォルダと同じ中身）で、毎回の最後に `pon_state_epNN.tgz` として Higgsfield のプロジェクト「ぽんの英単語（自動）」に保存されます。
このリポジトリの `pon/` は最初の版の写しです（このリポジトリには Claude からの push 権限がないため、自動実行は GitHub を使いません）。

| 場所 | 中身 |
|---|---|
| `RUNBOOK.md` | 自動実行の手順書（スケジュールの指示はこれを読むだけ） |
| `config/series.json` | キャラの参照画像・声・デザイン文・解剖文・モデル・予算などの固定設定 |
| `config/used_words.json` | 使用済みの単語（重複防止） |
| `config/theme_ideas.md` | テーマの候補 |
| `episodes/epNN.json` | 回ごとの企画・生成ジョブID・納品先 |
| `state.json` | 次の回の番号・途中の回・一時停止フラグ |
| `LOG.md` | 制作ログ |
| `pipeline/` | サンドボックスで動くスクリプト（第20回のスクリプトを回ごとの設定で動くようにしたもの） |

`pipeline/` の中身：`prompts.py`（生成リクエスト作成・企画チェック）、`fetch.py`（取り込み）、`register.py`（2コマ目の位置合わせ）、
`voice_spec.py` / `wcheck.py`（声のチェック）、`clip_check.py`（導入動画の崩れ）、`render_v.py` / `render_l.py`（静止画）、
`build_audio.py`（60.5秒の音声）、`encode.py`（書き出し）、`verify_final.py`（完成チェック）、`sheets.py`（目視用シート）、`run.sh`（入口）。

## 費用

1話あたり約20.5クレジット（絵21枚×0.5、導入動画7.5、声11本×0.23）。描き直しがあると数cr増えます。
**1日2話で約41cr/日、1か月で約1,250cr** です。残高が60cr未満になると自動で止まります（`state.json` が `paused`）。

## 止める・再開する

- 一時停止・再開・テーマの指定は、Claude に「ぽんの自動制作を止めて／再開して／次は○○のテーマで」と頼めば、サンドボックスの `state.json` や `theme_ideas.md` を書き換えます。
- スケジュール自体の停止・時刻変更は、Claude に「ぽんの自動制作のスケジュールを止めて／時刻を変えて」と頼む。
